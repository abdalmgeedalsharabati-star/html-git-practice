معلومات عن كوكو

كوكو هو مثال على صفحة ويب بسيطة تم إنشاؤها لتوضيح كيفية إنشاء صفحات HTML وربطها ببعضها البعض.

يمكنك استخدام هذه الصفحة لتجربة التعديلات ومراقبة كيفية تتبع التغييرات باستخدام Git و GitHub.

تأكد من حفظ التغييرات ومزامنتها مع المستودع الخاص بك على GitHub لمتابعة التعديلات خطوة بخطوة.

روابط مفيدة

  • W3Schools - مصدر ممتاز لتعلم HTML و CSS و JavaScript.
  • MDN Web Docs - وثائق شاملة لتطوير الويب.
  • Git - الموقع الرسمي لأداة Git.
  • GitHub - منصة استضافة المشاريع ومشاركة الأكواد.
